# 🏋️‍♂️ Fitness Workout App

A modern, fast, and responsive Fitness Application built with Next.js, React, TypeScript, and Tailwind CSS. Explore workout routines, save your favorites, and plan your daily exercise routines easily.

## 🌟 Key Features

1. **Comprehensive Workout Library:** Search and filter workouts by body part, difficulty level, and target muscle groups.
2. **Interactive Daily Planning:** Add workouts to your custom "Today's Plan" and manage your daily fitness goals.
3. **Save Workouts for Later:** Save your favorite exercises for quick access anytime.
4. **Interactive Toast Notifications:** Real-time feedback and notifications when adding, saving, or removing exercises.
5. **Responsive & Modern UI:** Optimized for all screen sizes with smooth page navigation and clean animations.

## 🛠️ Technologies Used

**Framework:** Next.js (App Router)
**Library:** React & TypeScript
**Styling:** Tailwind CSS
**Notifications:** React Hot Toast
**Icons:** Lucide React
